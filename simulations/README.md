# Stopping-Time and Belief-Accuracy Simulations

This project simulates belief updating under alternative update rules and compares stopping times, full-history accuracy, and consequential decisions.

## Reproduce the results

Use the project virtual environment and run:

```powershell
.\.venv\Scripts\python.exe main.py
```

The run is deterministic. The main configuration is defined at the top of
`main.py`: 10,000 Monte Carlo runs, true state 1, seed 20261002, stopping-time
cap of 10,000 signals, and fixed Brier horizons 10, 50, and 100.

## What `main.py` does

`main.py` runs Monte Carlo simulations for each update rule in `UPDATE_TYPES` and for each symmetric threshold level in `THRESHOLD_LEVELS`.

A threshold level such as `0.40` is interpreted symmetrically around `0.5`, so it corresponds to stopping bounds `(0.10, 0.90)`.

## Main result

The paper-ready output is:

- `results/tables/main_results.tex`: main LaTeX table
- `results/data/main_stopping_times.csv`: machine-readable source for Panel A
- `results/data/main_belief_accuracy.csv`: machine-readable source for Panel B
- `results/data/validation_report.txt`: automatic benchmark and common-history checks

The table combines mean and median stopping times with time-average excess Brier
scores over the first 10, 50, and 100 signals.

## Results directory

All generated files are kept under `results/`:

- `results/data/`: two table-source CSVs, two complete long-form datasets, and one validation report
- `results/tables/`: main table and appendix table
- `results/figures/`: stopping-time histograms and ECDFs

The directory can be deleted and regenerated by running `main.py`; source files
are never written there.

## Main code files

- `update_rules.py`: benchmark and bias-based belief update rules
- `signal_technology.py`: experimental signal process
- `simulation.py`: one stopping-time simulation for a given rule and threshold
- `stopping.py`: stopping condition
- `monte_carlo.py`: Monte Carlo experiments and statistical summaries
- `reporting.py`: CSV, LaTeX, and figure generation
- `validation.py`: reproducibility and benchmark checks
- `main.py`: visible configuration and pipeline orchestration

## Accuracy and decision measures

The true state is fixed at 1 in every run, while the decision maker starts from the
prior belief 0.5. Signal likelihoods are `(positive, neutral, negative) =
(0.45, 0.25, 0.30)`. The full-history benchmark is the Bayesian posterior that uses
every signal without resets.

The summary reports the stop rate; decision accuracy conditional on stopping;
unconditional correct and incorrect decision rates; Brier scores for the simulated
belief and the full-history benchmark; their difference (`excess_brier_score`); and
the mean absolute distance from the full-history posterior. Runs that reach the
horizon without crossing a bound are non-decisions, rather than forced choices.

The fixed-horizon exercise continues every path regardless of threshold crossings
and evaluates average squared prediction errors over periods 1--10, 1--50, and
1--100. All update rules receive
the same seeded signal histories; randomness used by reset rules is kept separate.
This makes the fixed-horizon Brier comparison independent of stopping-time length.
